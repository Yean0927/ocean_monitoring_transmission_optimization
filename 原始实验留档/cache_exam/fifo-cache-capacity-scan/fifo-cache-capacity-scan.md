# FIFO 缓存容量统一粒度扫描

本实验复用 packet-level 缓存报告中的连续 0–60 min ns-3 模型、30 s 链路状态更新、随机种子 31、六条数据流生成速率和 1472 B transport chunk 设置，仅将策略固定为 FIFO，并把缓存容量按统一粒度递增。

## 数据生成参数

本次 FIFO 缓存容量扫描使用六条数据流参数，数据流顺序统一为 `D1、D2、D3、D4、V1、I1`。其中 D1–D4 使用 packet-level 实验报告中提高 5 倍后的生成速率。V1 的生成速率取九个实际视频分别计算的‘文件大小÷时长’中位数，逻辑记录大小取九个完整视频文件大小的中位数；I1 沿用 packet-level 实验报告中的 5 s 图片生成周期。V1 和 I1 均在传输层切分为 1472 B chunk。表中的生成速率均指 payload 字节速率，不包含 UDP/IP 或链路协议首部。

| 数据流 | 逻辑记录大小(B) | transport payload(B) | 记录/transport chunk 生成频率 | 数据生成速率(Mbps) |
| --- | ---: | ---: | ---: | ---: |
| D1 大浮标气象数据 | 76 | 76 | 0.083333 Hz（12 s/次） | 0.000050665 |
| D2 普通气象数据 | 43 | 43 | 0.083333 Hz（12 s/次） | 0.000028665 |
| D3 波浪传感器数据 | 128 | 128 | 50 Hz（0.02 s/次） | 0.051200 |
| D4 ADCP 海流数据 | 1041 | 1041 | 0.008333 Hz（120 s/次） | 0.000069400 |
| V1 海洋视频数据 | 4354778 | 1472 | 中位记录周期约 20.89 s；约 141.63 Hz（chunk） | 1.667848 |
| I1 图片数据 | 258715 | 1472 | 0.2 Hz（记录）；约 35.2 Hz（chunk） | 0.413944 |

六条数据流的总 payload 生成速率为 **2.133140730 Mbps**，对应 60 min 理论产生量约为 **959.913328500 MB**；仿真输出的 `produced_mb = 959.913818000 MB`。V1 和 I1 的 chunks 在各自逻辑记录生成周期内均匀产生，最后一个 chunk 可小于 1472 B，但不改变对应数据流的总字节生成速率。

- 扫描粒度：10 MB（十进制，1 MB = 1,000,000 B）
- 判定条件：全程 `cache_evicted_mb = 0` 且 `source_dropped_mb = 0`；链路丢包单独统计
- 按该实验粒度得到的最小充足缓存：**120 MB**
- 该容量下：峰值缓存 117.310014 MB，缓存淘汰 0.000000000 MB

## 临界区间

前一个粒度点 110 MB 仍淘汰 7.310628 MB，因此实测临界容量位于 (110, 120] MB；本报告不把临界点插值为实测值。

说明：总丢失量 = 缓存淘汰量 + 链路丢失量。0 MB 时不暂存数据，生成后立即尝试发送；未能立即发送的数据记为缓存淘汰，该档缓存淘汰 236.977369 MB。判定缓存容量足够的条件为全程无缓存淘汰且无源端丢弃。
